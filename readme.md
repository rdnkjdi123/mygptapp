# Rep

A fast, mobile-first workout tracker prototype. Choose a body area, select an
exercise, and record weight-only sets with an automatic visual rest stopwatch.

## Open locally

1. Download `rep.html` from the repository.
2. Double-click `rep.html`.
3. The prototype opens directly in your default browser.

`rep.html` is a standalone copy of the prototype. The complete app—layout, styling,
and behavior—is contained in that one file.
There are no packages, folders, build steps, servers, or internet requirements.

## If the page looks blank

Confirm the downloaded file is named `rep.html` and is larger than 10 KB. If
GitHub shows a smaller file, the latest prototype changes have not been merged
into the branch you downloaded yet.
