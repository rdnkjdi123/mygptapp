# Rep

A fast, mobile-first workout tracker prototype. Choose a body area, select an
exercise, and record weight-only sets with an automatic visual rest stopwatch.
It has no packages, build process, server, or internet connection requirement.

## Open locally

1. Download the repository files, keeping the folders together.
2. Double-click `index.html`.
3. The prototype opens directly in your default browser.

There is nothing to install and no terminal command to run.
